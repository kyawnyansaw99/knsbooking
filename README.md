# KNSbooking – Room Booking & Reservation Management

A room and experience booking web app with live availability, double-booking protection and an admin dashboard.

**Live demo:** https://kyawnyansaw99.github.io/knsbooking/

## Features
- Live availability search with validation that blocks double-bookings and suggests other free time slots
- Responsive, accessible interface with photo-based room cards and a visual booking timeline
- Admin page to approve, decline and cancel reservations, with a searchable reservation log
- State managed with React Context and localStorage

## Tech stack
React · Vite · Tailwind CSS · React Router · Lucide icons

## Run locally
```bash
npm install
npm run dev
```
Then open http://localhost:5173

## Build
```bash
npm run build
```
